# Security

stayfrosty is a security tool, so a hole in it is a hole in every box it manages.

## Reporting a vulnerability

Please report it privately through GitHub: on this repository, open the Security tab and choose
"Report a vulnerability". Do not open a public issue.

Include what you found, how to reproduce it, and which version or commit you tested. You will get a
reply within a week.

## Scope

In scope: anything in this repository, including the hardening it applies to a box, how it handles
API tokens, and anything `frosty verify` claims to check but does not.

Out of scope: vulnerabilities in Hetzner, Cloudflare, cloudflared, OpenSSH or Ubuntu themselves.
Report those to their vendors.
